# Image Files Guide - Where to Place Your Images

## 📁 File Locations and Names

Place your images in the following locations with these exact file names:

### 1. Logo
**Location:** `public/images/logo.png`  
**Used in:** Navigation bar and Footer  
**Recommended size:** 40x40px minimum (will scale automatically)  
**Format:** PNG or SVG (transparent background preferred)

### 2. Hero App Screenshot
**Location:** `public/images/screenshots/hero-app.png`  
**Used in:** Hero section (right side, mobile preview)  
**Recommended size:** 375x812px (iPhone size) or similar mobile aspect ratio  
**Format:** PNG

### 3. Reviews Feature Screenshot
**Location:** `public/images/screenshots/reviews-feature.png`  
**Used in:** Reviews feature section  
**Recommended size:** 1200x675px (16:9 aspect ratio)  
**Format:** PNG

### 4. Social Media Feature Screenshot
**Location:** `public/images/screenshots/social-feature.png`  
**Used in:** Social Media feature section  
**Recommended size:** 1200x675px (16:9 aspect ratio)  
**Format:** PNG

### 5. Polls Feature Screenshot
**Location:** `public/images/screenshots/polls-feature.png`  
**Used in:** Polls feature section  
**Recommended size:** 1200x675px (16:9 aspect ratio)  
**Format:** PNG

### 6. Story Times Feature Screenshot
**Location:** `public/images/screenshots/story-times-feature.png`  
**Used in:** Story Times feature section  
**Recommended size:** 1200x675px (16:9 aspect ratio)  
**Format:** PNG

## 🎨 Image Tips

1. **Optimize your images** - Use tools like TinyPNG or ImageOptim to reduce file size
2. **Use high resolution** - Export at 2x or 3x for retina displays
3. **Consistent style** - Ensure all screenshots match your app's design style
4. **File names must match exactly** - Case-sensitive, use the exact names listed above

## 🚀 After Adding Images

Once you've added all images with the correct names and locations, they will automatically appear on the waitlist page. No code changes needed - the Image components are already active!
