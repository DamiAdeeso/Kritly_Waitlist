# Images Directory

Place your images here according to the following structure:

## Logo Files
- `logo.png` or `logo.svg` - Main Kritly logo (recommended: 400x400px or larger)
- `logo-white.png` - White version of logo (optional)

## Screenshots
- `screenshots/` - Place all Figma design screenshots here
  - `screenshot-1.png`
  - `screenshot-2.png`
  - etc.

## Assets
- `assets/` - Other assets like favicons
  - `favicon.ico` - 32x32px or 16x16px
  - `apple-touch-icon.png` - 180x180px

## Usage

Once you add your logo, update `app/page.tsx` to use it instead of the placeholder.
