# Screenshot Images

Place your Figma design screenshots here. The waitlist page expects the following images:

## Required Screenshots

1. **hero-app.png** - Main hero section app preview (mobile view)
   - Recommended: 375x812px (iPhone size) or similar mobile aspect ratio
   - This appears in the hero section

2. **reviews-feature.png** - Reviews feature showcase
   - Recommended: 1200x675px or 16:9 aspect ratio
   - Shows the reviews functionality

3. **social-feature.png** - Social media integration feature
   - Recommended: 1200x675px or 16:9 aspect ratio
   - Shows social media features

4. **polls-feature.png** - Polls feature showcase
   - Recommended: 1200x675px or 16:9 aspect ratio
   - Shows the polls functionality

5. **story-times-feature.png** - Story Times feature showcase
   - Recommended: 1200x675px or 16:9 aspect ratio
   - Shows Story Times video feature

## Image Guidelines

- Use PNG format for best quality
- Optimize images for web (use tools like TinyPNG or ImageOptim)
- Ensure images are high resolution but optimized for fast loading
- Match the design style from your Figma screens

## Adding More Screenshots

If you want to add more feature showcases, you can:
1. Add the image to this folder
2. Update `app/page.tsx` to include additional feature sections
3. Follow the same pattern as existing features
